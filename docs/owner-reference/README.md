### 準備したこと

商品データ・商品ページ・ドラゴンフルーツの固定ページを、
**すべて用意して非公開（下書き）の状態で置いています。**

- 商品名「ドラゴンフルーツ 400g」／600円（税込・送料別）
- 内容量「1パック 400g以上」
- 「1パックに1〜数個（400g以上になるようお詰めします）」と明記
- 「今季ご用意できるのは5点です」と表示
- 1回のご注文で選べるのは5点まで
- お届け時期「8月下旬から12月ごろまで」

### 公開する前に、2つ伺いたいことがあります

**1. ドラゴンフルーツは、1個口（60サイズ）に何パックまで入りますか。**

送料をいただく金額が、この数で決まります。
これが分からないと送料を計算できないため、公開できません。

龍眼とスターフルーツのときに伺ったのと同じ内容です
（龍眼は6パックまで、スターフルーツは6個までで伺っています）。

ライチは「350gなら3点・500gなら2点まで」と伺っていますが、
これはライチのパックでの条件なので、ドラゴンフルーツには当てはめていません。
勝手に当てはめると、送料が足りなくなる可能性があります。

なお60サイズは重さ2kgまでなので、400g×5パックだと保冷材を入れて
2kgを超えてしまいます。おそらく3〜4パックが上限かと思いますが、
実際に箱に入れてみた数をお知らせください。

**2. 常温便で送りますか。クール便（冷蔵）で送りますか。**

いまサイトの送料は、すべてクール便の料金で計算しています。
ただしドラゴンフルーツは、ハワイ大学の資料では6℃で低温障害
（果肉が水っぽく透ける・黒ずむ）が出るとされていて、
10℃前後での保存がすすめられています。

クール便の冷蔵が0〜10℃なので、冷やしすぎになる心配があります。
常温便にする場合は送料が変わるので、料金表を作り直します。

### 「5個限定」について、正直にお伝えしておきたいこと

**このサイトは、売れた数を数えていません。**

「1回のご注文で5点まで」は設定できます。
ですが「全部で5点売れたら自動で売り切れにする」ことは、いまの作りではできません。
お一人が5点買われたあとに、別の方がまた5点注文できてしまいます。

5点だけのご用意なら、次のどちらかになります。

- **運用で止める**（すぐできます）
  ご注文が入るとメールが届くので、5点出たらご連絡ください。
  すぐに「売り切れ」に切り替えます。
  切り替えるまでのあいだに次のご注文が入る可能性は残ります。
- **在庫を数える仕組みを作る**（1〜2日いただきます）
  売れた数をサイトが覚えて、5点で自動的に売り切れになります。
  来季まとまった数を売るなら、作っておく価値があります。

とりあえず5点でしたら、運用で止めるほうで十分だと思います。

## 2026年10月3日 在庫を数える仕組みを作りました

### なぜ作ったか

> 現在の供給状況が、5個とは言わず、たくさん出来る予定なのですが、
> 注文が入ってから、2〜3営業日のうちに、出荷可能に出来る品が5個という
> 感じです
>
> ただ、今年、「5個出来ました！」売り切れ⇒「5個出来ました！」売り切れ
> ⇒以下略 を何回か繰り返すことになる可能性があります…
>
> 2日待つ程度であれば、個数カウントの仕組みを作られた方が、
> 良いように思います

この繰り返しを、ご連絡なしで回せるようにしました。

### 農園でしていただくこと

**https://www.yamakawaengei.com/admin/stock** を開いてください。

1. 合言葉を入れる（別途お伝えします）
2. いま出荷できる数を入れて「この数にする」を押す

これだけです。押した時点から数え直します。
あとはご注文が入るたびに自動で減り、**0になると自動で売り切れ**になります。
また出荷できる数が揃ったら、同じ画面でもう一度入れてください。

「売り切れにする」ボタンもあります。すぐ止めたいときにお使いください。

スマートフォンで開ける画面です。検索結果には出ません。

### お客様に見えること

- 商品ページ … 「ただいまご用意できるのは◯点です」
- 売り切れたとき … 「ただいま売り切れです」とご案内し、カートに入れられなくなる
- 数量の選択 … 残りの数より多くは選べない

**「残り◯点」「お早めに」とは書いていません。**
急かす表示にはせず、事実だけをお伝えしています。

### 数え方（念のため）

**残り ＝ ご用意した数 − そのあと売れた数**

毎回この計算をやり直しています。1つずつ減らしていく方式にしていないので、
通信が重なっても、同じ通知が2回届いても、数がずれません。

なお、ほぼ同時に2人がご注文手続きに入った場合だけ、
わずかに多く受け付けてしまう可能性が残ります（数秒の間だけです）。
その場合はご注文のメールで気づけますので、ご連絡ください。

### 山川園芸さまへのお願いごと

いまのところ、ご用意した数の最初の値は「5点」で入れてあります。
