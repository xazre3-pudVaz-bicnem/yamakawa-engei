## 2026-09-16 LINE（販売開始の条件）

| 商品 | 売価 | 規格 | 販売時期 | 60サイズ1個口の上限 |
| --- | --- | --- | --- | --- |
| スターフルーツ | 400円 | 1個 | 10月〜4、5月 | 8個 |
| 龍眼 | 400円 | 1パック 100g | 9月〜10月頃 | 6個 |
| 完熟ホワイトサポテ | 400円 | 1パック 150g | 9月頃 | 6個 |

- 配送はすべてヤマト運輸のクール便（冷蔵）、60サイズ1個口のみ
- すべて保冷バッグ・保冷剤つき
- **スターフルーツは櫻井植物園のものを販売する。写真も櫻井植物園から**
- 櫻井植物園の紹介ページは後日つくる

### サイトへの反映

- products.ts に3商品を追加（`ryugan-100g` / `white-sapote-150g` / `starfruit`）
- スターフルーツは10月からのため `coming_soon`。**10月になったら `in_stock` に変える**
- 商品に `maxPerParcel`（1個口に入る最大数）を追加し、送料を個数で計算できるようにした
- トップページに「取り扱っている果物」の一覧を追加
- ヘッダー・下部バー・販売状況の表示を、ライチの状況ではなく
  「いま買える商品があるか」で出し分けるようにした

### 確認が必要な点

1. **価格は税込という前提で入れています。** 日本の総額表示にならい税込としましたが、
   税別であればお知らせください。
2. **複数の種類をまとめて買われたときの個口数は伺っていません。**
   いまは「1個口に対する占有率（例：龍眼1個=1/6）」を足し上げて計算しています。
   龍眼3＋サポテ3 → 1個口、龍眼6＋サポテ6 → 2個口 という見積もりです。
   実際と違う場合はお知らせください。送料の過不足に直結します。
3. スターフルーツ1個あたりの重さは伺っていません（送料は個数で計算しているため支障なし）。
4. 一度に注文できる数は、1個口の上限に合わせています
   （龍眼6・サポテ6・スター8）。在庫に応じて変えられます。

## 2026-09-17 LINE（前回の確認への回答と変更）

いただいた回答

1. **価格は税込で正しい。** → 変更なし（税込のまま）
2. **混載の個口数は、こちらの見積もりで正しい。**
   「竜眼3＋サポテ3 ⇔ 1個口／竜眼6＋サポテ6 ⇔ 2個口 の認識であってます」

4. **スターフルーツの1個口の最大数を 8個 → 6個 に変更。**
